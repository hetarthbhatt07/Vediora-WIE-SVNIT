3. MANAGING AWS COSTS ($20 CREDITS PROTECTION)
================================================================================

- WHEN YOU ARE NOT USING THE APP:
  1. Go to AWS EC2 Console -> Instances.
  2. Select your instance -> Click "Instance state" -> "Stop instance".
  3. While STOPPED, AWS charges $0.00 for compute hours!

- WHEN YOU ARE READY TO PRESENT TO JUDGES / TEST:
  1. Go to AWS EC2 Console -> Select instance -> "Instance state" -> "Start instance".
  2. Copy the new Public IPv4 address.
  3. Connect via PowerShell:
     ssh -o ServerAliveInterval=60 -i "vediora-key.pem" ubuntu@<PUBLIC-IP>
  4. cd WIE-SVNIT-FN
  5. npm start
  6. Open: http://<PUBLIC-IP>:3000

================================================================================
6. OPTIONAL: RUN IN BACKGROUND 24/7 (USING PM2)
================================================================================

If you ever want it to keep running even after closing your laptop terminal:

    sudo npm install -g pm2
    cd ~/WIE-SVNIT-FN
    pm2 start "npm start" --name "vediora"
    pm2 save
    pm2 startup

- To check status:
    pm2 status

- To view logs:
    pm2 logs

- To stop the background app:
    pm2 stop vediora

- To restart the background app:
    pm2 restart vediora
